1. O que é DOM? (Document Object Model)

      O DOM é uma representação estruturada da página web criada pelo navegador assim que ele carrega o HTML. Pense nele como uma "árvore genealógica" (ou árvore de objetos) onde cada tag HTML, texto ou atributo se torna um objeto manipulável pelo JavaScript.

    • Relação com HTML:

      O HTML é o arquivo de texto bruto (o rascunho), enquanto o DOM é a "casa construída" na memória. O DOM reflete exatamente o que está na tela. Quando você muda o HTML com JavaScript (usando o DOM), a página web se atualiza instantaneamente sem precisar recarregar.

  2. O que é um Nó (Node)?

    • Um nó (node) é a unidade básica da árvore DOM. Tudo em um documento HTML é um nó: Elementos (Element Node): São as tags HTML, como < div >, < p >, < h1 >.Eles formam a estrutura.
    • Texto (Text Node): É o conteúdo de texto real dentro das tags. Ex: O "Olá" em < p >Olá< / p >.
    • Atributos (Attribute Node): São os atributos das tags, como class, id, src, href. Geralmente, eles são considerados propriedades do nó de elemento, não filhos diretos dele.

  3. Métodos para selecionar elementos (DOM Manipulation)

    • getElementById('id'): Busca um único elemento específico através do seu atributo id. É o método mais rápido.

      • Exemplo: document.getElementById('cabecalho');

    • querySelector('seletor'): Busca o primeiro elemento que coincida com um seletor CSS (tag, classe ou id).

      • Exemplo: document.querySelector('.botao-azul'); (seleciona a primeira classe)

    • querySelectorAll('seletor'): Busca todos os elementos que coincidem com o seletor CSS e retorna uma lista (NodeList) com eles.

      • Exemplo: document.querySelectorAll('p'); (seleciona todos os parágrafos).

  4. Diferença entre innerHTML e innerText

      Ambos mudam o conteúdo de um elemento, mas de formas diferentes:

    • innerHTML: Retorna ou altera o conteúdo incluindo as tags HTML. Se você definir el.innerHTML = 'oi', o navegador renderizará "oi" em negrito.

    • innerText: Retorna ou altera apenas o texto visível para o usuário. Tags HTML incluídas nele serão tratadas como texto puro, não renderizadas.

    • Dica: innerText é melhor para performance quando você quer manipular apenas o texto.

  5. O que são Eventos?

    Eventos são ações ou ocorrências que acontecem no sistema (navegador) que você está programando, geralmente causadas pelo usuário (clique, rolagem) ou pelo navegador (carregamento completo da página). O JavaScript pode "ouvir" e responder a esses eventos.

    • onclick: Dispara quando o usuário clica em um elemento (ex: botão).

      • Ex: button.onclick = function() { alert('Clicou!'); };

    • onchange: Dispara quando o valor de um elemento muda (comum em campos de formulário, < select > ou < input > ao perder o foco).

      • Ex: input.onchange = function() { console.log('Valor mudou'); };

    • onmouseover: Dispara quando o ponteiro do mouse passa por cima de um elemento.

      • Ex: div.onmouseover = function() { div.style.color = 'red'; };
